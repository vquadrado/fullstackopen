# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note right of browser: The user types a note into the text field and clicks Save
    Note right of browser: The spa.js submit handler calls preventDefault so the page is not reloaded
    Note right of browser: The browser creates a note object, adds it to the local notes list, and redraws the list

    browser->>server: POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa
    activate server
    Note right of server: The server saves the note from the JSON body
    server-->>browser: 201 Created
    deactivate server

    Note right of browser: The browser stays on the same page. No redirect and no further HTTP requests
```
